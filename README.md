# /monthly — сводка месяца для отчёта в Hive

Команда для Claude Code. Собирает из локальных транскриптов сессий (`~/.claude/projects/…/*.jsonl`,
те же файлы, что ежедневно уходят в `/report`) один текстовый файл: по дням — проекты, сайты,
задачи, итог каждой сессии, оценка времени. Затем Claude дописывает «Резюме месяца».
Файл вы загружаете в Hive → «Отчёты», и ИИ Hive строит по нему one-pager.

Рядом кладёт архив «Сессии Claude Code — <месяц>.zip» с ужатыми сессиями (без «размышлений» и
длинных выводов инструментов, секреты вырезаны). Его отправляют боту Hive @kg_export_bot, и отчёт
появляется ещё и в Hive → Coding → «Мой отчёт» с ИИ-анализом. Части не больше 45 МБ.

Ничего никуда не отправляется. Секреты и IP вырезаются теми же правилами, что в `/report`.

## Если сессий за начало месяца «нет»

Claude Code хранит транскрипты `cleanupPeriodDays` — по умолчанию 30 дней от последней активности —
и удаляет старше. Поэтому 2-го числа на диске нет 1–2 чисел прошлого месяца, 15-го — уже половины.
`/monthly` восстанавливает такие дни из истории ваших запросов (`~/.claude/history.jsonl`, она не
удаляется): проект, задачи и время есть, итогов и инструментов нет, в архив для бота такие сессии
не попадают. В шапке отчёта и в статистике такие дни перечислены явно («по истории запросов»).

Чтобы транскрипты не пропадали, `install.sh` ставит `"cleanupPeriodDays": 90` в
`~/.claude/settings.json` (если задано меньше). Вернуть прежнее — удалить ключ.

## Установка

```sh
curl -fsSL https://raw.githubusercontent.com/ashaposhnikova-hub/claude-monthly/main/install.sh | sh
```

Проверка без создания файла: `node ~/.claude/skills/monthly/monthly.mjs --dry-run` — покажет дни,
сессии, часы и какие дни собраны только по истории запросов. Обновление — та же команда установки.

## Как пользоваться

1. В новой сессии Claude Code: `/monthly` → месяц (Enter = прошлый).
2. Claude собирает файл `~/Documents/Отчёты Hive/Отчёт Claude Code — <месяц> <год>.txt`,
   пишет резюме и показывает его. Поправьте, если что-то не так.
3. Hive → «Отчёты» → загрузите .txt → проверьте one-pager → «Отправить на одобрение».
4. Архив «Сессии Claude Code — <месяц>.zip» отправьте файлом боту @kg_export_bot
   (Telegram должен быть привязан: Hive → Coding → Telegram → `/link КОД`).

`/report` по-прежнему делаем каждый день: `/monthly` читает те же сессии, но только с вашего компьютера.

## Параметры

`--month 2026-08` · `--out <путь>` · `--name "Фамилия Имя"` · `--dry-run` · `--no-zip`

## Как считается время

Объединение времени ваших запросов по всем сессиям за день; параллельные окна не складываются;
паузы дольше 30 минут не считаются. Это оценка, а не учёт рабочего времени — часы в Hive идут из трекера.
